# Yandex Mail Personalizer

Полуавтоматическая подготовка персонализированных писем в Яндекс.Почте
по списку из `.txt` файла. Расширение **не отправляет письма самостоятельно** —
пользователь проверяет и нажимает «Отправить» вручную.

## Установка

### Chrome / Яндекс.Браузер (режим разработчика)

1. Скачайте папку `yandex-mail-personalizer` целиком.
2. Откройте `chrome://extensions/` (Chrome) или `browser://extensions/` (Яндекс.Браузер).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.
5. Закрепите иконку расширения на панели.

Иконки (необязательно): положите `icon16.png`, `icon48.png`, `icon128.png`
в корень и добавьте в `manifest.json` поля `icons` и `action.default_icon`.

## Формат файла
Иван;ivan@example.com
Иван;ivan2@example.com
Сергей;serg@example.com


- Кодировка UTF-8.
- Файл считается **отсортированным по имени** — подряд идущие одинаковые
  имена объединяются в одно письмо.
- Первый email группы → поле «Кому».
- Остальные email группы → поле «Скрытая копия».
- Строки с ошибкой останавливают валидацию.

## Сценарий работы

1. Загрузите `.txt` в popup.
2. Нажмите «Начать» — расширение откроет Яндекс.Почту, создаст письмо,
   заполнит «Кому» и «Скрытую копию».
3. **Вручную выберите шаблон** в форме письма.
4. Расширение проверит, что тема не пустая и в теле есть `{Имя}`,
   заменит плейсхолдер на имя текущей группы.
5. Проверьте письмо и нажмите «Отправить».
6. Откройте popup и нажмите «Далее», чтобы перейти к следующей группе.

## Ограничения

- Расширение не обходит капчу, лимиты и антиспам-системы Яндекс.Почты.
- Не работает с вложениями.
- Не ведёт детальную историю отправок (см. папку «Отправленные»).
- Устойчивость к изменениям вёрстки Яндекс.Почты ограничена:
  используются стабильные селекторы (`id`, `name`, `aria-label`),
  но при значительных изменениях UI потребуется обновление `content/content.js`.
